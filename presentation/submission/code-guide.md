## 2. 树是怎样画出来的（没有用图片）

全部是代码画的，开始时画一次，之后重复使用。

1. **277 `makeForest`**：开始时画 12 种树（阔叶 4、白杨 2、尤加利 2、松树 2、灌木 2）。
2. **每棵树先画在 900×900 的隐形画布上**，用 `rngN(种子)`，所以每次都一样。
3. **树枝是递归**（`branch`）：一根枝分 2–3 根，每根短 0.7 倍、细 0.66 倍，用曲线画得有点弯。
4. **叶子是"点"（dabs）**：在每个枝尖周围撒很多小椭圆。每个点有一个"亮度"：上面和左边比较亮。
5. **从暗画到亮**：先画暗的点，再画亮的，所以树冠有立体感，像画笔点出来的。
6. **松树**不用树枝：叶点填满一层层的圆锥。**灌木**是一个低低的半圆。
7. 画好后裁切成小图（sprite），记下树有多高（`g.top`）。
8. **369 `drawBrushTree`**：在街上按距离缩放这张小图，加阴影；远的树盖一层雾色（`hazeSprite`），融进空气里。
9. **790 `drawForest`**：每块地 3 排树，随机选种类和高度，从远画到近。砍掉时树往外倒、慢慢变透明，留下树桩。

## 3. 手：ml5 handPose + webcam

### 流程

| 步骤 | 行号 | 做什么 |
|---|---|---|
| 按 C 开相机 | 1950 `startHands` | |
| 载入 ml5 | 1961 | 第一次才从 unpkg 载入 ml5@1.0.1 |
| 开 webcam | 1956 | `createCapture(VIDEO)`，320×240，隐藏 |
| 建模型 | 1957 | `ml5.handPose({ maxHands: 2 })`，最多 2 只手 |
| 开始侦测 | 1957 | `detectStart(handVideo, gotHands)`：每帧自动把结果交给 `gotHands` |
| 读结果 | 1976 `gotHands` | 每只手 21 个点（wrist、index_finger_tip…） |
| 镜像 | 1984 | `x = 1 - p.x / 320`，像照镜子 |
| 分左右手 | 1971 `sideOfLabel` + 投票 | 左手管街的左边，右手管右边 |
| 判断手势 | 2016 `handShape` | 一指、张开、拳头 |
| 砍和盖 | 2027 `handFeedSide` | 横扫 = 砍，往上举 = 盖 |
| 走路 | 2058 `sampleMotion` | 看身体动不动来走路 |

### 手势怎样判断（2016–2025）

每根手指比较两个距离：**指尖到手腕** ÷ **中间关节到手腕**。
- 大于 1.18：手指是直的
- 小于 1.02：手指是弯的
- 中间：不确定

结果：
- 只有食指直：**point**，盖住宅
- 3 根以上直：**open**，盖商店
- 全部弯：**fist**，盖大楼和工厂
- 不清楚：什么都不盖

用比例，所以手离相机远或近都一样准。

### 动作

- **砍（2038–2041）**：0.4 秒内横向移动超过画面 18%，而且横向多过上下。
- **盖（2030、1779 `deliberateLift`）**：手往上移动就加楼层。要先举高 6% 才开始（小抖动不算），砍完 0.6 秒内不算。
- **大小（1774 `handLevel`）**：手的高度。画面下半部 = 小，到胸口 = 中，过头 = 大。
- **防抖（2033–2034）**：同一个手势要连续看到 3 次才换。

### 走路（2058 `sampleMotion`）

- 每 66 毫秒，把影像缩成 48×36 灰阶图，跟上一张比。
- 只看中间（身体），而且把手和手臂盖掉，所以挥手不会走路。
- 开始时站着不动 2 秒做校准（2081–2084），量背景的噪音。
- 8 次里有 6 次在动，才算走路（2088–2089）。
- 2093 `bodySpeed`：动得越多走得越快，最快会跑。

## 4. 怎样调整

| 想改什么 | 行号 | 改法 |
|---|---|---|
| 手势太难认 | 2018 | `1.18` 改小（如 1.12），`1.02` 改大（如 1.06） |
| 手不稳、乱认 | 1980 | `0.6` 信心值改大（如 0.75） |
| 手势切换太慢 | 2034 | `candN >= 3` 改成 2 |
| 砍太难 | 2040 | `0.18` 改小（如 0.14） |
| 砍太容易（误砍） | 2040 | `0.18` 改大（如 0.24） |
| 举手太容易盖 | 1783 | `0.06` 改大 |
| 大小的高度 | 1774 | `0.5`（小/中）和 `0.72`（中/大） |
| 走路太敏感或不够 | 现场按 `[` / `]` | 2415–2416，每按一次 ±25% |
| 雾霾快慢 | 1693 | `/ 20` 改小 = 更快变灰；`0.35` 改大 = 变得更快 |

**现场最好用的：** 走路不准就按 `[` `]`；光线不好，就开灯，手放在胸前，离相机 1–2 米。
