# Street memory — 30 October 2026

The same district now retains its plot layout across yearly laps. Selected plots become taller, vacant investment buildings; a FORMERLY sign keeps the previous name visible. Ordinary pavement residents become less numerous as local vacancy rises. Investor purchases and the player’s ownership survive chunk regeneration. A third of plots are exempt from scheduled redevelopment, retaining purchase opportunities.

This is a conceptual model of displacement, not a housing-market simulation. Residents currently disappear as vacancy increases; moving-out animations and population-responsive sound are future refinements. Memory lasts for the current run and resets on restart or page reload.

Validation: `node walk/street-memory.test.cjs`; `node --check walk/sketch-all.js`; local browser walking and annual progression checked.
